# 評価用テストセット

`npm run eval` が読むテストセットです。既定は `testset.json`。別のファイルを使うときは `npm run eval -- data/eval/別ファイル.json`。

> **注意**: 今の `testset.json` は書き方を示すサンプルです。ファイル名・ページ・内容は架空なので、
> 実際に取り込んだ PDF に合わせて書き換えてください（要件の「正答率 80%」を測るには数十問以上を推奨）。

## 1問の書き方

```json
{
  "id": "q001",
  "question": "年次有給休暇は入社後いつから、何日付与されますか？",
  "out_of_scope": false,
  "expected_points": ["入社から6か月経過後に付与される", "付与日数は10日"],
  "evidence": [{ "file_name": "就業規則.pdf", "page": 12 }]
}
```

| 項目 | 内容 |
|---|---|
| `id` | 問題を見分ける ID。重複不可 |
| `question` | 社員が実際に聞きそうな質問文 |
| `out_of_scope` | `true` = 文書に答えが無い質問（範囲外）。「該当なし」が返れば正解 |
| `expected_points` | 期待する答えの要点。回答が**すべて**押さえていれば正解。範囲外なら `[]` |
| `evidence` | 根拠のファイル名（取り込んだ PDF のファイル名そのまま）とページ番号（1始まり）。範囲外なら `[]` |

## 範囲外の質問の作り方

要件「文書に無い判断・推論は必ず『該当なし』」を確かめるため、次の種類を混ぜてください。

- 文書に書かれていない事柄（例: 来年度の賞与の見込み）
- 文書から推論・判断しないと答えられないもの（例: 「私の残業は違法か」）
- 社内文書と無関係な一般知識（例: 消費税率の歴史）

## 指標の定義

| 指標 | 計算方法 | 目標 |
|---|---|---|
| 正答率 | 範囲内の質問のうち、要点をすべて押さえ矛盾も無い回答の割合（Claude が採点） | 80% 以上 |
| 出典付与率 | 「回答した」ケースのうち、出典が1件以上付いた割合 | 100% |
| 該当なし率 | 範囲外の質問のうち「該当なし」を返した割合 | 100% |
| 参考: 範囲内なのに該当なし | 閾値（`SIMILARITY_THRESHOLD`）が厳しすぎないかの目安 | 低いほど良い |
| 参考: 根拠一致 | 回答の出典に `evidence` のページが含まれる割合 | 高いほど良い |

レポートは `reports/eval/`（git 管理外）に Markdown と JSON で保存されます。
